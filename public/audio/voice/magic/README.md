# Magical spell voice assets

Place natural female voice MP3 files here to replace browser speech synthesis in magical mode.

The root files are the default Ava voice. Additional voice variants live under:

- `variants/emma/`
- `variants/maisie/`
- `variants/libby/`
- `variants/natasha/`
- `variants/sonia/`

Expected filenames:

- `spell-01-alohomora.mp3`
- `spell-02-colloportus.mp3`
- `spell-03-glacius.mp3`
- `spell-04-finite-incantatem.mp3`
- `spell-05-lumos.mp3`
- `spell-06-nox.mp3`
- `spell-07-lumos-solem.mp3`
- `spell-08-lumos-maxima.mp3`
- `spell-09-revelio.mp3`
- `spell-10-muffliato.mp3`
- `spell-11-rennervate.mp3`

Magical mode randomly chooses one available variant for each spoken spell.

Use newly generated or properly licensed voice assets. Do not copy audio from films, games, trailers, or other copyrighted source media.
